# SKU 与活动页获取

抢购台要的是两样东西：**打开哪个页面**（`url`）和 **它是哪个 SKU**（`sku`，用来区分日志与状态）。两者可以不一致 —— 这点很关键。

## 一、先分清两种页面

| 页面类型 | 长什么样 | 什么时候用 |
|---|---|---|
| 商品页 | `https://item.m.jd.com/product/100012043978.html` | 预约按钮、抢购按钮都在商品页上时 |
| 活动页 | `https://pro.m.jd.com/mall/active/xxxx/index.html`（各种 `h5.m.jd.com` / `pro.m.jd.com`） | 预约按钮只在活动页（截图里「每周5有特价」那种楼层）时 |

**判定方法**：在抢购台里点「诊断当前页」，看 `buttons` 输出。

- 有 `预约` / `立即抢购` / `加入购物车` → 这个 URL 就能直接用。
- 只有 `去逛逛` / `分享` / 一堆商品图 → 这是活动页外壳，要么换成具体商品页，要么把活动页 URL 填进 `url` 并让词典去点楼层里的商品卡（成功率低，不推荐）。

配置里 `url` 留空时，App 会自动用 `https://item.m.jd.com/product/{sku}.html`。

## 二、四种拿 SKU 的方法

### 方法 1：App 内分享（最快）

京东 App → 打开商品 → 右上角「分享」→「复制链接」。粘贴进抢购台的「SKU 或商品链接」，失焦自动解析。

支持的链接格式：

```
https://item.m.jd.com/product/100012043978.html
https://item.jd.com/100012043978.html
https://u.jd.com/xxxxxxxx          ← 短链，解析不出，需要在浏览器打开一次拿长链
【京东】xxx https://item.m.jd.com/product/100012043978.html  ← 带文案的整段也能解析
100012043978                        ← 纯 SKU
```

解析规则：优先匹配 `product/` 或 `item.m?\.jd\.com/` 后的数字；否则取第一个 ≥6 位的数字串。

### 方法 2：活动页里点进商品再分享

活动页 → 点商品图 → 进入商品详情 → 分享 → 复制链接。

注意：活动页的「预约」按钮有时绑的是**活动 SKU**，而详情页是**主 SKU**，两者可能不同。若发现商品页没有「预约」按钮，就把活动页 URL 直接填进 `url`，`sku` 仍填详情页 SKU 用于日志区分。

### 方法 3：浏览器地址栏

手机浏览器打开 `m.jd.com` → 搜商品 → 进详情 → 地址栏里的数字就是 SKU。

### 方法 4：抢购台自己的诊断

1. 抢购台里把 `url` 先填成活动页；
2. 点「诊断当前页」；
3. 日志里的 `PROBE: {"sku":"100012043978",...}` 直接给出当前页解析到的 SKU。

## 三、填进配置

`config/app-config.json` 的 `items`：

```json
{
  "alias": "15枚鲜蛋",
  "sku": "100012043978",
  "url": "https://item.m.jd.com/product/100012043978.html",
  "expectPrice": "4.90",
  "priority": 1,
  "enabled": true,
  "reserve": true
}
```

| 字段 | 说明 |
|---|---|
| `alias` | 界面与日志里的显示名，随便写，中文更好认 |
| `sku` | 纯数字 |
| `url` | 实际打开的页面；留空自动按 SKU 拼 |
| `expectPrice` | 仅用于人工核对（截图里是券后价 4.90 / 3.90 / 9.90 / 6.90），程序不校验价格 |
| `priority` | 越小越先加载；超过 4 个时只取前 4 个 |
| `enabled` | 是否参与抢购 |
| `reserve` | 是否先尝试点「预约」 |

截图对应的四个商品（价格来自活动页，SKU 需你自填）：

| 商品 | 券后价 | 已预约人数（截图时点） |
|---|---|---|
| 15 枚鲜蛋 | ¥4.90 | 14 万+ |
| 12 卷纸 | ¥3.90 | 7000+ |
| 10 盒牛奶 | ¥9.90 | 1 万+ |
| 6 罐可乐 | ¥6.90 | 5000+ |

**「已预约人数」就是竞争对手数量。** 鸡蛋 14 万人抢，纸巾只有 7000 人 —— 同样的手速，纸巾命中率天然高一个数量级。真要用，优先把纸巾/可乐放 `priority: 1`。

## 四、常见坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 解析出 0 或空 | 短链 `u.jd.com` 里没有 SKU | 浏览器打开短链，拿跳转后的长链 |
| 解析出错误数字 | 链接里带了订单号/活动 id | 手工只留 `product/` 后面那段 |
| 商品页 404 | SKU 下架或区域限制 | 用活动页 URL 兜底 |
| 抢购台里是 PC 版页面 | UA 被识别成桌面 | 确认 `url` 用的是 `item.m.jd.com`（带 `m`） |
| 页面要求选规格 | 商品有多规格，需先选 | 在预热阶段手动选一次，页面会记住 |
